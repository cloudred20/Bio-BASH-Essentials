## HPC and Nextflow Toolkit

This repository brings together two practical resources for running computational biology and data science workflows on HPC systems:

**1. HPC-Essentials**  
Concise, practical notes and scripts for navigating High-Performance Computing environments.

**2. Nextflow-Pipeline-Template**  
Starter template for building reproducible, scalable Nextflow pipelines suitable for SLURM-based clusters.
